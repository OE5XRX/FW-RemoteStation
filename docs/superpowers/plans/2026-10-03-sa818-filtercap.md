# SA818 FilterCap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose SA818 audio filters (pre-emphasis, HPF, LPF) as three agent-steerable bool `Setting` capabilities via the existing `module describe`/`execute` shell protocol.

**Architecture:** Add `sa818_filter_flags filters` to `Sa818Context` (RAM shadow, initialized to `SA818_FILTER_ALL`). Implement three `Setting` subclasses (`FilterPreEmphasisCap`, `FilterHpfCap`, `FilterLpfCap`) — each reads/writes its single bit in the shadow and calls the existing `sa818_at_set_filters(dev, flags)`. Register all three in `g_caps[]`. No new files; no driver changes; no persistence in firmware.

**Tech Stack:** C++20, Zephyr RTOS, ETL 20.48.0, `west twister`, pytest + `SA818Simulator`, clang-format-18.

**Spec:** `memory://feature/tx-audio-fw-filtercap/brief` (Kontor project memory)

## Global Constraints

- No dynamic memory allocation (`new`, `delete`, `malloc`, `std::vector`, `std::string`, etc.)
- No exceptions, no RTTI
- clang-format-18 must produce no diff (`.clang-format` at repo root, LLVM base, 2-space indent, 160-col)
- All `[[nodiscard]]` return codes must be checked — do not discard `sa818_at_set_filters` result
- Boot defaults must match `SA818State` defaults in `SA818Simulator` (all three filters `True` → `SA818_FILTER_ALL`)
- FW is role-agnostic: no access-control or persistence logic
- Native_sim-first: all new paths must be exercised by the pytest suite on `native_sim/native/64`

## Review Focus

- **Set one filter, others unchanged:** Setting `filter_pre_emphasis off` must NOT silently clear HPF/LPF. Each `onSet` must read the current shadow bitmask, flip exactly one bit, then call `sa818_at_set_filters`. Covered by `test_module_filter_independence`.
- **`driver_error` not `bool_cast` when device not ready:** All three `onSet`/`onGet` must guard `ctx_.ready()` before touching the driver. Covered implicitly by the test fixture (device is always ready in native_sim, but the guard path is the same as other caps).
- **`1`/`0`/`true`/`false`/`on`/`off` all accepted:** `parse_bool` already handles all forms; must not add a new parser. Covered by `test_module_filter_bool_forms`.
- **`describe` set assertion does not silently expand:** `test_module_describe_valid_json` uses `==` not `>=`, so any unintended extra capability would fail CI. Update the exact set.
- **`status` snapshot includes all three filter values:** `test_module_status_snapshot` checks `set(v) ==` exactly; add the three filter names or CI fails.

  ```cpp
  class FilterPreEmphasisCap : public Setting {
  public:
    explicit FilterPreEmphasisCap(Sa818Context &ctx) : ctx_(ctx) {}
    const FieldSpec &spec() const override { return FILTER_PRE_EMPHASIS_SPEC; }

  protected:
    Result onSet(const char *value) override {
      if (!ctx_.ready()) {
        return Result::err("driver_error");
      }
      std::optional<bool> v = parse_bool(value);
      if (!v) {
        return Result::err("bad_value");
      }
      sa818_filter_flags new_flags = *v ? static_cast<sa818_filter_flags>(ctx_.filters | SA818_FILTER_PRE_EMPHASIS)
                                        : static_cast<sa818_filter_flags>(ctx_.filters & ~SA818_FILTER_PRE_EMPHASIS);
      if (sa818_at_set_filters(ctx_.dev, new_flags) != SA818_OK) {
        return Result::err("driver_error");
      }
      ctx_.filters = new_flags;
      return Result::okBool(*v);
    }

    Result onGet() override {
      if (!ctx_.ready()) {
        return Result::err("driver_error");
      }
      return Result::okBool(!!(ctx_.filters & SA818_FILTER_PRE_EMPHASIS));
    }

  private:
    Sa818Context &ctx_;
  };
  ```
